Furti AI

“Compiling LLM plans into local OpenCV reflexes to eliminate VLA latency.”

A high-speed desktop automation agent that won 1st Place (Winner) at VINHACK 2026 as a 1st-year fresher! Competing against experienced developers and multi-year teams at graVITas '26, Furti AI achieved the top award by solving the latency and token-cost bottlenecks of standard Vision-Language-Action (VLA) agents.

Standard VLA desktop agents make expensive multimodal LLM calls on every single screen frame, causing unacceptable latency and high operating expenses. Furti AI solves this by calling the model exactly once per novel task to synthesize the workflow, then compiling high-level plans into local cropped image template reflexes that replay via OpenCV in milliseconds with zero recurring token expense.

  • ▹
    1st Place Hackathon Achievement: Awarded 1st prize at VINHACK by demonstrating end-to-end desktop automation executing sub-millisecond reflexes as a 1st-year student team.
  • ▹
    Single-Call Plan Compilation: Queries the model once per novel task, caching the cropped template image, coordinates, and metadata locally into an instant execution skill.
  • ▹
    Autonomous Dynamic Re-anchoring: When UI confidence dips below the threshold, a Reflex Realigner automatically re-anchors the template dynamically or triggers the Brain Planner to re-synthesize.

ImmuneFleet

“Cars share antibodies, not data.”

A decentralized, privacy-preserving cybersecurity framework for connected electric vehicle fleets, modeled after biological immunology. Our team advanced through competitive evaluation to reach the Final Round (Grand Finale) of Sustainathon 2026.

When an electric vehicle faces a zero-day exploit—such as a malicious CAN bus frame flood targeting steering or braking ECUs—other vehicles on the road share the exact same vulnerability. However, sharing raw diagnostic telemetry exposes sensitive user data like GPS coordinates, vehicle VINs, velocities, and travel habits. ImmuneFleet decentralizes collective fleet defense by generating and sharing lightweight, anonymous threat defense rules (antibodies) without ever leaking raw vehicle telemetry.

  • ▹
    Dual-Layer Privacy Defense: Raw CAN logs are redacted on-vehicle down to relative frame indices and payloads before LLM analysis (Layer 1). A strict deterministic allowlist validator (validator.py) rejects all extra or hallucinated fields (Layer 2).
  • ▹
    Instant Warning & 3-Car Consensus: A single vehicle's detection applies local containment immediately and shares an ALERT-only notification across the fleet. Fleet-wide hard blocks require consensus from 3 distinct cryptographically signed vehicles.
  • ▹
    Peer Sandbox Testing & Staged Rollout: Healthy vehicles simulate the antibody rule against standard driving and emergency deceleration scenarios before rollout, safeguarding safety-critical functions.

Formora AI

“Tell it what the form needs to do. It writes the form.”

An intelligent form generation engine and companion browser extension built during the high-speed DevJams ’26 hackathon at VIT Vellore's annual techno-management fest (graVITas 2026).

Traditional form building requires repetitive HTML scaffolding, CSS alignment, and brittle manual validation rules. Formora AI solves this by allowing developers and creators to simply prompt what data needs to be collected in natural language. Formora then automatically drafts, structures, styles, and validates production-ready interactive web forms with built-in schema checks.

  • ▹
    Prompt-to-Form Synthesis: Converts natural language requirements into clean semantic input fields, validation rules, and structured layout components in seconds.
  • ▹
    Client-Side Schema & Logic Validation: Automatically injects regex validation patterns, required constraints, and conditional show/hide logic without manual boilerplate.
  • ▹
    Dual Workspace (Web & Extension): Features a standalone web builder and a companion browser extension to generate, inspect, and embed forms directly within existing workflows.
